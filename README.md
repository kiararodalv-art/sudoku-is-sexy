# Sudoku is Sexy 

Un Sudoku jugable construido desde cero en JavaScript vanilla, HTML y CSS — sin frameworks, sin librerías, solo lógica y DOM puro.

## Sobre el proyecto

Este proyecto nació como ejercicio de consolidación de fundamentos de JavaScript: matrices, funciones, loops anidados y manipulación del DOM. Incluye validación completa de las reglas del Sudoku (fila, columna y cuadrante 3x3), feedback visual en tiempo real, y un diseño minimalista inspirado en estética "quiet luxury".

## Funcionalidades

- Tablero interactivo de 9x9 generado dinámicamente
- Validación en tiempo real de fila, columna y cuadrante 3x3
- Feedback visual de errores
- Celdas del puzzle original bloqueadas
- Detección automática de partida ganada
- Botón de reinicio que restaura el puzzle original

## Tecnologías

- JavaScript (vanilla, sin frameworks)
- HTML5
- CSS3

## Qué aprendí

- Manejo de matrices (arrays de arrays) y loops anidados
- Manipulación del DOM (`createElement`, `appendChild`, event listeners)
- La diferencia entre copia superficial y copia profunda de arrays
- Especificidad en CSS
- Estructurar lógica de negocio separada de la interfaz
